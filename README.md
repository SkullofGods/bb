# Справочник опергруппы — мини-приложение Telegram для Boom Beach

Статическое мини-приложение (HTML + CSS + JS, без сборки) со всей справочной
информацией по Boom Beach для опергруппы: операции, войска, прототипы, оборона,
герои, статуи, калькулятор канонерки, гайды на русском и архив скринов из чата.

Данные собраны с англоязычной вики `boombeach.fandom.com`, русские названия —
с её русского раздела, тактические описания и гайды написаны под нашу группу,
скриншоты — из выгрузки чата.

## Что внутри

```
webapp/                 само мини-приложение (это и выкладывается в сеть)
  index.html
  css/app.css
  js/                   data.js, ui.js, calc.js, views.js, app.js
  data/                 все данные приложения (json)

    proto_troops.json   прототипы войск
    gunboat.json        канонерка и её способности
    defenses.json       оборонительные здания
    proto_defenses.json оборонные прототипы
    heroes.json         герои
    buildings.json      постройки
    meta.json           механики, события, справочник
    ops.json            таблица 24 операций
    bases.json           каталог силовых баз операций (схемы разведки)
    ru_text.json        русские описания и тактика (правится руками)
    guide.json          гайды и FAQ (правится руками)
  img/                  иконки с вики (webp) + img/bases — схемы баз

tools/
  build.py              пересобирает справочник с вики
  build_bases.py        собирает каталог баз из выгрузки чата
  ru_names.py           словарь русских названий и заголовков таблиц
  cache/                кеш страниц вики (можно удалить, скачается заново)

server.py               сам веб-сервер
Dockerfile              запуск на bothost (только латиница)
```

---

## Быстрый старт: посмотреть на компьютере

```bash
py -3 bot.py
```

Откроется на `http://localhost:3000`. С телефона в той же сети — по адресу,
который напечатает скрипт.

Вне Telegram приложение работает полностью, только не подхватывает тему
клиента и кнопку «Назад».

## Как выложить и подключить к Telegram

Telegram открывает мини-приложения только по **https**, поэтому приложение
нужно где-то разместить.

### Вариант 1. bothost (как остальные боты)

Точка входа — **`bot.py`**, именно его запускает хостинг. Он всегда поднимает
веб-сервер (`server.py`) на `0.0.0.0` и порту из `PORT` (по умолчанию **3000**),
а бота добавляет рядом, только если тот настроен.

Важно, что `bot.py` не падает, когда бота нет. Раньше он завершался с ошибкой
«не задан BOT_TOKEN» — процесс умирал сразу, в логах не было ни строчки от
приложения, только `Received SIGTERM`, а домен отдавал `Bad Gateway`.

Что проверить в настройках бота:

1. **«Использовать домен»** — включить и передеплоить. Только после этого
   хостинг передаёт `PORT` и начинает проксировать домен на контейнер.
   Без этого `Bad Gateway` останется при любом коде.
2. **«Использовать собственный Dockerfile»** — включить и сделать
   **новый деплой** (рестарта мало). Без него автоопределение может принять
   проект за Node.js: в репозитории почти всё — картинки и скрипты из `webapp`.
3. Живость: `https://твой-домен/health` должен отвечать `ok`,
   а `https://твой-домен/` — открывать приложение.
4. В логах при удачном старте есть строка
   `Мини-приложение слушает 0.0.0.0:<порт>`. Если её нет — приложение вообще
   не стартовало, смотри лог сборки.

Переменные окружения не нужны: мини-приложению бот не требуется.
Чтобы появился бот с кнопкой «Справочник», задай `BOT_TOKEN` и адрес
приложения (`WEBAPP_URL`, либо `APP_LINK` со ссылкой из `/newapp`),
а в `requirements.txt` раскомментируй `aiogram`.

Dockerfile держи **только на латинице** — по документации bothost кириллица
в нём может молча оборвать сборку.

### Вариант 2. GitHub Pages (бесплатно, 10 минут)

1. Создай репозиторий на GitHub, например `bb-miniapp`.
2. Залей в него **содержимое папки `webapp`** (именно содержимое: `index.html`
   должен лежать в корне репозитория).

   ```bash
   cd webapp
   git init
   git add .
   git commit -m "Справочник опергруппы"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/bb-miniapp.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
4. Через пару минут приложение будет по адресу
   `https://ТВОЙ_ЛОГИН.github.io/bb-miniapp/`.

### Вариант 3. Netlify / Cloudflare Pages

Перетащить папку `webapp` в веб-интерфейс — получишь https-адрес сразу.

### Вариант 4. Свой сервер рядом с ботом

Если у тебя уже крутится бот на aiohttp, достаточно отдать папку статикой:

```python
app.router.add_static("/bb/", path=BASE_DIR / "webapp", name="bb", show_index=False)
```

и открыть её по https через nginx / Caddy.

### Подключение к боту (BotFather)

1. `@BotFather` → `/newapp` → выбрать бота.
2. Название, описание, картинка 640×360.
3. **Web App URL** — адрес из пункта выше.
4. Короткое имя, например `spravochnik`.
5. BotFather выдаст ссылку вида `https://t.me/ИМЯ_БОТА/spravochnik`.

Эту ссылку можно **закрепить в группе** — она открывает приложение прямо из чата,
бот при этом ничего делать не должен.

Дополнительно, если хочется кнопку в меню бота:

```bash
py -3 -m pip install aiogram
set BOT_TOKEN=123456:ABC...
set WEBAPP_URL=https://ТВОЙ_ЛОГИН.github.io/bb-miniapp/
set APP_LINK=https://t.me/ИМЯ_БОТА/spravochnik
py -3 bot.py
```

## Как править содержимое

Почти всё содержимое — обычные json-файлы, код трогать не нужно.
После правки просто обнови страницу (и залей файл на хостинг).

| Что поменять | Где |
|---|---|
| Правила опергруппы, гайды, советы | `webapp/data/guide.json` → `articles` |
| Базы операций и их схемы | `webapp/data/bases.json` |
| Частые вопросы | `webapp/data/guide.json` → `faq` |
| Русские описания юнитов и обороны | `webapp/data/ru_text.json` |
| Названия операций | `tools/ru_names.py` → `OPS`, затем `py -3 tools/build.py` |
| Русские названия юнитов и зданий | `tools/ru_names.py` → `RU`, затем `py -3 tools/build.py` |

### Формат гайда (`guide.json` → `articles`)

```json
{
  "id": "my-guide",
  "icon": "⚔️",
  "title": "Заголовок",
  "sub": "Подзаголовок",
  "tags": ["операции"],
  "blocks": [
    {"t": "h", "v": "Подзаголовок внутри статьи"},
    {"t": "p", "v": "Абзац текста"},
    {"t": "ul", "v": ["пункт", "пункт"]},
    {"t": "ol", "v": ["шаг 1", "шаг 2"]},
    {"t": "tip", "v": "Зелёная плашка «Совет»"},
    {"t": "warn", "v": "Красная плашка «Важно»"},
    {"t": "table", "h": ["Колонка"], "r": [["значение"]]}
  ]
}
```

### Формат описания юнита (`ru_text.json`)

Ключ — `группа:id`, например `troops:zooka` или `defenses:boom-cannon`.
`id` видно в адресе карточки: `#/p/troops/zooka`.

```json
"troops:zooka": {
  "s": "Короткое описание одной фразой",
  "p": ["плюс", "плюс"],
  "m": ["минус"],
  "u": ["как играть", "ещё совет"]
}
```

## Как обновить данные с вики

Когда в игре выйдет обновление и вики поправят:

```bash
rmdir /s /q tools\cache
py -3 tools/build.py
```

Пересоберёт `data/*.json` и докачает недостающие иконки.
Ручные файлы (`ru_text.json`, `guide.json`, `bases.json`) при этом не трогаются.

После правки файлов в `webapp/js` или `webapp/css` подними номер версии
в `webapp/index.html` (`?v=5` → `?v=6`), иначе у людей останется старая версия
из кеша браузера.

## Базы операций

Главный раздел: **Операции → операция → базы этой операции → схема базы**.

Список баз на вики не публикуется: набор силовых баз генерируется заново при
каждом запуске операции. Поэтому каталог собирается из скриншотов разведки —
на них видно название базы, её уровень и максимум очков силы.

Сейчас в каталоге 15 баз (19 схем), вытащенных из выгрузки чата.
Операция проставлена там, где это прямо следует из переписки
(партия скринов за 13.12.2024 — базы с двумя ядрами с дуплексности).

### Добавить базу или привязать её к операции

1. Сделай в игре скрин разведки базы (виден её заголовок с названием и очками силы).
2. Положи картинку в `webapp/img/bases/`, маленькую копию — в `webapp/img/bases/t/`.
3. Допиши запись в `webapp/data/bases.json`:

```json
{
  "id": "manticore",
  "name": "Мантикора",
  "ops": [23, 24],
  "note": "Два ядра, ракетницы по центру",
  "shots": [
    {"img": "img/bases/manticore-1.webp", "thumb": "img/bases/t/manticore-1.webp",
     "lvl": 161, "fp": 300, "date": "17.10.2024"}
  ]
}
```

`ops` — номера операций, на которых база встречалась; именно по ним база
появляется на странице операции. Если база уже есть в каталоге — достаточно
дописать номер в её `ops`.

Если скриншотов много и они лежат в выгрузке чата, удобнее дописать их в список
`BASES` в `tools/build_bases.py` и запустить:

```bash
py -3 -m pip install pillow
py -3 tools/build_bases.py
```

## Про данные

* Цифры взяты с англоязычной вики Boom Beach и могут отставать от последнего
  обновления игры. На каждой карточке внизу есть ссылка на страницу-источник.
* Русские названия войск, обороны и построек — официальные, с русского раздела
  вики. Для прототипов официальных названий в вики нет, использованы принятые
  в сообществе; английское название всегда показано рядом.
* Названия операций — перевод плюс то, как их зовут в нашем чате
  («бочка», «фокс», «бастион», «порез», «надя», «дупло»).
* Бонусы в калькуляторе вводятся руками: приложение не знает, какие у тебя
  статуи и гравировки.
