# Справочник опергруппы — мини-приложение Telegram для Boom Beach

Статическое мини-приложение (HTML + CSS + JS, без сборки) со всей справочной
информацией по Boom Beach для опергруппы: операции, войска, прототипы, оборона,
герои, статуи, калькулятор канонерки, гайды на русском и архив скринов из чата.

Данные собраны с англоязычной вики `boombeach.fandom.com`, русские названия —
с её русского раздела, тактические описания и гайды написаны под нашу группу,
скриншоты — из выгрузки чата.

---

## Что внутри

```
webapp/                 само мини-приложение (это и выкладывается в сеть)
  index.html
  css/app.css
  js/                   data.js, ui.js, calc.js, views.js, app.js
  data/                 все данные приложения (json)
    troops.json         войска
    proto_troops.json   прототипы войск
    gunboat.json        канонерка и её способности
    defenses.json       оборонительные здания
    proto_defenses.json оборонные прототипы
    heroes.json         герои
    buildings.json      постройки
    meta.json           механики, события, справочник
    ops.json            таблица 24 операций
    ru_text.json        русские описания и тактика (правится руками)
    guide.json          гайды, сленг, FAQ (правится руками)
    gallery.json        подписи к скринам из чата
  img/                  иконки с вики (webp) + img/gallery — скрины из чата

tools/
  build.py              пересобирает data/ и img/ с вики и из выгрузки чата
  ru_names.py           словарь русских названий и заголовков таблиц
  cache/                кеш страниц вики (можно удалить, скачается заново)

serve.py                локальный сервер для проверки
bot.py                  необязательный бот с кнопкой «Справочник»
```

---

## Быстрый старт: посмотреть на компьютере

```bash
py -3 serve.py
```

Откроется на `http://localhost:8765`. С телефона в той же сети — по адресу,
который напечатает скрипт.

Вне Telegram приложение работает полностью, только не подхватывает тему
клиента и кнопку «Назад».

## Как выложить и подключить к Telegram

Telegram открывает мини-приложения только по **https**, поэтому папку `webapp`
нужно выложить на любой статический хостинг. Самый простой путь — GitHub Pages.

### Вариант 1. GitHub Pages (бесплатно, 10 минут)

1. Создай репозиторий на GitHub, например `bb-miniapp`.
2. Залей в него **содержимое папки `webapp`** (именно содержимое: `index.html`
   должен лежать в корне репозитория).

   ```bash
   cd webapp
   git init
   git add .
   git commit -m "Справочник опергруппы"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/bb-miniapp.git
   git push -u origin main
   ```

3. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
4. Через пару минут приложение будет по адресу
   `https://ТВОЙ_ЛОГИН.github.io/bb-miniapp/`.

### Вариант 2. Netlify / Cloudflare Pages

Перетащить папку `webapp` в веб-интерфейс — получишь https-адрес сразу.

### Вариант 3. Свой сервер рядом с ботом

Если у тебя уже крутится бот на aiohttp, достаточно отдать папку статикой:

```python
app.router.add_static("/bb/", path=BASE_DIR / "webapp", name="bb", show_index=False)
```

и открыть её по https через nginx / Caddy.

### Подключение к боту (BotFather)

1. `@BotFather` → `/newapp` → выбрать бота.
2. Название, описание, картинка 640×360.
3. **Web App URL** — адрес из пункта выше.
4. Короткое имя, например `spravochnik`.
5. BotFather выдаст ссылку вида `https://t.me/ИМЯ_БОТА/spravochnik`.

Эту ссылку можно **закрепить в группе** — она открывает приложение прямо из чата,
бот при этом ничего делать не должен.

Дополнительно, если хочется кнопку в меню бота:

```bash
py -3 -m pip install aiogram
set BOT_TOKEN=123456:ABC...
set WEBAPP_URL=https://ТВОЙ_ЛОГИН.github.io/bb-miniapp/
set APP_LINK=https://t.me/ИМЯ_БОТА/spravochnik
py -3 bot.py
```

## Как править содержимое

Почти всё содержимое — обычные json-файлы, код трогать не нужно.
После правки просто обнови страницу (и залей файл на хостинг).

| Что поменять | Где |
|---|---|
| Правила опергруппы, гайды, советы | `webapp/data/guide.json` → `articles` |
| Словарь сленга чата | `webapp/data/guide.json` → `slang` |
| Частые вопросы | `webapp/data/guide.json` → `faq` |
| Русские описания юнитов и обороны | `webapp/data/ru_text.json` |
| Названия операций и наш сленг | `tools/ru_names.py` → `OPS`, затем `py -3 tools/build.py wiki` |
| Русские названия юнитов и зданий | `tools/ru_names.py` → `RU`, затем `py -3 tools/build.py wiki` |

### Формат гайда (`guide.json` → `articles`)

```json
{
  "id": "my-guide",
  "icon": "⚔️",
  "title": "Заголовок",
  "sub": "Подзаголовок",
  "tags": ["операции"],
  "blocks": [
    {"t": "h", "v": "Подзаголовок внутри статьи"},
    {"t": "p", "v": "Абзац текста"},
    {"t": "ul", "v": ["пункт", "пункт"]},
    {"t": "ol", "v": ["шаг 1", "шаг 2"]},
    {"t": "tip", "v": "Зелёная плашка «Совет»"},
    {"t": "warn", "v": "Красная плашка «Важно»"},
    {"t": "table", "h": ["Колонка"], "r": [["значение"]]}
  ]
}
```

### Формат описания юнита (`ru_text.json`)

Ключ — `группа:id`, например `troops:zooka` или `defenses:boom-cannon`.
`id` видно в адресе карточки: `#/p/troops/zooka`.

```json
"troops:zooka": {
  "s": "Короткое описание одной фразой",
  "p": ["плюс", "плюс"],
  "m": ["минус"],
  "u": ["как играть", "ещё совет"]
}
```

## Как обновить данные с вики

Когда в игре выйдет обновление и вики поправят:

```bash
rmdir /s /q tools\cache
py -3 tools/build.py wiki
```

Пересоберёт `data/*.json` и докачает недостающие иконки.
Ручные файлы (`ru_text.json`, `guide.json`) при этом не трогаются.

## Как пересобрать галерею из новой выгрузки чата

1. Экспортируй чат из Telegram Desktop в **HTML с фотографиями**.
2. Положи папку `ChatExport_ГГГГ-ММ-ДД` рядом с `webapp`.
3. ```bash
   py -3 -m pip install pillow
   py -3 tools/build.py gallery
   ```

В галерею попадают только широкие (игровые) скриншоты, они жмутся в webp:
большие до 900 px, превью до 260 px.

## Про данные

* Цифры взяты с англоязычной вики Boom Beach и могут отставать от последнего
  обновления игры. На каждой карточке внизу есть ссылка на страницу-источник.
* Русские названия войск, обороны и построек — официальные, с русского раздела
  вики. Для прототипов официальных названий в вики нет, использованы принятые
  в сообществе; английское название всегда показано рядом.
* Названия операций — перевод плюс то, как их зовут в нашем чате
  («бочка», «фокс», «бастион», «порез», «надя», «дупло»).
* Бонусы в калькуляторе вводятся руками: приложение не знает, какие у тебя
  статуи и гравировки.
